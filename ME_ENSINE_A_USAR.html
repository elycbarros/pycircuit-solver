🎓 Me Ensine a Usar o pycircuit-solver!

O Guia Prático, Visual e Passo a Passo para Analisar Circuitos com Python e Rust

🚀 1. O Que é Este Projeto em 1 Minuto?

O pycircuit-solver é uma "calculadora inteligente de circuitos elétricos" para o seu terminal e seus scripts Python.

Você informa como os componentes estão conectados entre si através de nós (pontos de conexão), e o motor calcula automaticamente:

  • A tensão em cada ponto do circuito.
  • A corrente e a potência em cada componente.
  • O circuito equivalente de Thévenin e Norton com curva de máxima potência.
  • A resposta em frequência (CA/Bode) para indutores e capacitores.
  • O comportamento real com tolerância de fábrica (Monte Carlo acelerado em Rust).
💡 A Única Regra de Ouro da Topologia:
Todo circuito elétrico precisa de uma referência de zero volts. No pycircuit-solver, o nó de referência (o Terra / GND) sempre deve se chamar "0".

🛠️ 2. Instalação Expressa

No seu terminal (com Python 3.10+):

# 1. Clone o repositório
git clone https://github.com/elycbarros/pycircuit-solver.git
cd pycircuit-solver

# 2. Instale o pacote em modo de desenvolvimento
pip install -e .

# 3. (Opcional) Instale as dependências para gráficos e testes
pip install -e .[dev]

Pronto! Agora você tem a biblioteca Python e o comando pycircuit disponíveis no seu terminal.

🧪 3. Lição 1: Seu Primeiro Circuito em Python

Vamos resolver um divisor de tensão clássico: fonte de 12V ligada a dois resistores (4Ω e 6Ω).

Nó 1 Nó 2 ( + )───────[ R1: 4Ω ]─────────┬─────── ( - ) │ │ [ V1: 12V ] [ R2: 6Ω ] │ │ ( - )──────────────────────────┴─────── Terra: "0"

Crie um arquivo meu_circuito.py:

from circuit_solver import Circuit, VoltageSource, Resistor, solve

# 1. Descreva os componentes e como eles se ligam nos nós
elementos = [
    VoltageSource("V1", node_p="1", node_n="0", voltage=12.0),
    Resistor("R1", node_p="1", node_n="2", resistance=4.0),
    Resistor("R2", node_p="2", node_n="0", resistance=6.0),
]

# 2. Crie o circuito
circuito = Circuit(elementos)

# 3. Resolva o circuito!
solucao = solve(circuito)

# 4. Imprima os resultados
print(solucao.summary())
======================================================================== MNA Solution Summary ======================================================================== Node Voltages: V(1) = 12.000000 V V(2) = 7.200000 V ------------------------------------------------------------------------ Branch Currents: I(R1) = 1.200000 A I(R2) = 1.200000 A I(V1) = -1.200000 A ========================================================================

Você pode acessar qualquer grandeza diretamente:

v2 = solucao.V("2")         # 7.2 Volts
i_r1 = solucao.I_resistor("R1")      # 1.2 Amperes
p_r1 = solucao.P_resistor("R1")      # +5.76 W dissipados (power_audit usa -5.76 W para absorção)

🏷️ 4. Lição 2: Use Notações de Bancada ("10k", "4k7", "100u")

Na vida real ninguém escreve 4700 ou 0.000010. Use parse_value para converter direto:

from circuit_solver.core.validator import parse_value

r_base = parse_value("4k7")    # 4700.0 Ohms
c_filtro = parse_value("100u") # 0.0001 Farads
v_fonte = parse_value("12V")   # 12.0 Volts
r_mega = parse_value("1MEG")   # 1_000_000.0 Ohms

🔍 6. Lição 4: Equivalente de Thévenin e Norton

Simplifique uma rede inteira conectada entre dois terminais e descubra o ponto de máxima transferência de potência:

# Extrai Thévenin entre nó 2 e terra "0", abrindo o gráfico da curva P_max

from circuit_solver.engine.thevenin import thevenin_norton

th = thevenin_norton(circuito, node_a="2", node_b="0")

print(f"Vth:  {th.V_th:.3f} V")

🎛️ 7. Lição 5: Circuitos com Amplificador Operacional (Op-Amp)

Monte um Amplificador Inversor com ganho $A_v = -R_f / R_1 = -5$:

Rf: 50k ┌──────[===]──────┐ │ │ Vin ──[===]───┬───────────┴── Vout R1: 10k │ |\ └───|- \ | >────── Vout ┌───|+ / _│_ |/ /// (GND)
from circuit_solver import Circuit, VoltageSource, Resistor, OpAmp, solve

circuito_opamp = Circuit([
    VoltageSource("Vin", "in", "0", 2.0),
    Resistor("R1", "in", "vn", 10_000.0),
    Resistor("Rf", "vn", "vout", 50_000.0),
    Resistor("Rload", "vout", "0", 10_000.0),
    OpAmp("U1", in_p="0", in_n="vn", out="vout", gnd="0")
])

sol = solve(circuito_opamp)

print(f"Tensão de Entrada: {sol.V('in'):.2f} V")
print(f"Terra Virtual:     {sol.V('vn'):.6f} V  (idealmente 0V)")
print(f"Tensão de Saída:   {sol.V('vout'):.2f} V (Ganho exato de -5x)")

⏱️ 9. Lição 7: Análise Transitória no Tempo (Carga/Descarga RC, RL e RLC)

Quer acompanhar como a tensão sobe ou desce a cada microssegundo ao ligar uma chave ou aplicar um pulso?

No Terminal (CLI):

# Simular de 0 a 10 ms com passo de 10 μs e abrir o gráfico da forma de onda
pycircuit tran filtro_passa_baixas.cir --tstop 0.01 --dt 1e-5 --node out --plot

Em Código Python (Circuito RC com Degrau):

from circuit_solver import (
    Circuit,
    VoltageSource,
    Resistor,
    Capacitor,
    StepWaveform,
    solve_transient,
)

# Circuito RC com degrau de 0V para 10V
circuito_rc = Circuit([
    VoltageSource("V1", "1", "0", 10.0, waveform=StepWaveform(v1=0.0, v2=10.0, t_step=0.0)),
    Resistor("R1", "1", "2", 1000.0),
    Capacitor("C1", "2", "0", 1e-6, ic=0.0),
])

# Simula 5 milissegundos (5 constantes de tempo tau)
sol_tran = solve_transient(circuito_rc, t_stop=0.005, dt=1e-5, uic=True)

print(sol_tran.summary())
print(f"Tensão em 1 ms (1 tau): {sol_tran.V('2')[100]:.3f} V  (≈ 63.2% de 10V)")
print(f"Tensão final em 5 ms:   {sol_tran.V('2')[-1]:.3f} V   (≈ 99.3% de 10V)")

🎲 10. Lição 8: Análise Estatística de Monte Carlo (Acelerada em Rust)

Resistores reais têm tolerância de 5% ou 10%. O que acontece quando 50.000 circuitos forem fabricados?

# CLI: 10.000 simulações com 5% de tolerância e histograma P5/P95
pycircuit monte-carlo divisor.cir -n 10000 -t 0.05 --plot

Em Python, usando o acelerador multi-thread nativo em Rust:

from circuit_solver import monte_carlo

# 50.000 simulações completas em milissegundos
resultado = monte_carlo(circuito, n_samples=50_000, seed=42)
print(resultado.summary())

⚡ 11. Lição: Semicondutores & Newton-Raphson

Componentes não-lineares como diodos e transistores não possuem uma resistência fixa: a corrente depende exponencialmente da tensão. O pycircuit-solver detecta automaticamente a presença de semicondutores e aciona o motor de Newton-Raphson com amortecimento SPICE (pnjlim e fetlim).

Exemplo com Diodo Retificador PN (Equação de Shockley):

from circuit_solver import Circuit, VoltageSource, Resistor, Diode, solve

circuito = Circuit([
    VoltageSource("V1", "1", "0", 5.0),
    Resistor("R1", "1", "2", 1000.0),
    Diode("D1", "2", "0", Is=1e-14, n=1.0),
])

sol = solve(circuito)
print(f"V(2) = {sol.V('2'):.4f} V  (queda de tensão típica ~0.7V)")
print(f"I(D1) = {sol.I_diode('D1') * 1e3:.3f} mA")
print(f"Convergência em {sol.iterations} iterações (tol < 1e-6)")

📈 12. Lição: Varredura Paramétrica DC (.dc sweep)

Varra fontes de tensão, corrente ou valores de resistências em uma faixa para traçar curvas de transferência ($V_{out} \times V_{in}$) e curvas características de dispositivos.

# No terminal:
pycircuit dc circuito.cir --sweep V1 0 10 0.1 --node out --plot
# Em Python:
from circuit_solver import Circuit, VoltageSource, Resistor, dc_sweep

circuito = Circuit([
    VoltageSource("VIN", "in", "0", 0.0),
    Resistor("R1", "in", "out", 1000.0),
    Resistor("R2", "out", "0", 1000.0),
])

res = dc_sweep(circuito, "VIN", 0.0, 10.0, 0.5)
print(f"Curva gerada com {len(res.sweep_values)} pontos!")

🧲 13. Lição: Transformadores e Acoplamento Magnético Mútuo

Simule indutores mutuamente acoplados ($M = k \sqrt{L_1 L_2}$) e transformadores lineares com isolamento galvânico ou relação de espiras arbitrária ($n = \sqrt{L_1/L_2}$).

from circuit_solver import Circuit, VoltageSource, Transformer, Resistor, solve_ac

# Transforma 120 V em 60 V (relação 2:1)
circuito = Circuit([
    VoltageSource("V1", "1", "0", voltage=120.0, ac_mag=120.0),
    Transformer("T1", p1="1", n1="0", p2="2", n2="0", L1=10.0, L2=2.5, coupling=0.999),
    Resistor("RL", "2", "0", 100.0),
])

sol = solve_ac(circuito, frequency=60.0)
print(f"Tensão Secundário: {sol.V_mag('2'):.2f} V")  # ~60.0 V

🎯 16. Lição: Sensibilidade Analítica, Pior Caso (WCA / EVA) & RSS

Quantifique o impacto da variação de cada resistor da fábrica na saída através do Método da Rede Adjunta (Tellegen), obtendo sensibilidades analíticas exatas $\partial V / \partial p$ em $O(1)$.

# No terminal:
# Análise de pior caso com cálculo de extremos não-lineares (EVA)
pycircuit wca circuito.cir -t out --tol 0.05
# Em Python:
from circuit_solver import Circuit, VoltageSource, Resistor, analyze_sensitivity

circuito = Circuit([
    VoltageSource("V1", "1", "0", 10.0),
    Resistor("R1", "1", "2", 1000.0, tolerance=0.05),
    Resistor("R2", "2", "0", 1000.0, tolerance=0.05),
])

res = analyze_sensitivity(circuito, target_node="2", default_source_tolerance=0.0)
print(res.summary())

⚡ 17. Lição: Transiente em Rust (>1.000.000 passos/s) & Auditoria Energética

Simulação ultra-rápida no domínio do tempo com modelos companion (Trapezoidal e Backward Euler). A matriz MNA é fatorada em LU uma única vez e cada passo é resolvido em microssegundos em Rust compilado com medição contínua de conservação de energia e perdas Joule.

# No terminal:
pycircuit tran circuito_rlc.cir --tstop 10m --dt 10u --backend rust --plot
# Em Python:
from circuit_solver import Circuit, VoltageSource, Resistor, Capacitor, solve_transient

circuito = Circuit([
    VoltageSource("V1", "1", "0", 10.0),
    Resistor("R1", "1", "2", 1000.0),
    Capacitor("C1", "2", "0", 1e-6),
])

res = solve_transient(circuito, t_stop=5e-3, dt=1e-5, backend="rust", uic=True)
print(f"Passos resolvidos: {len(res.time)}")
print(f"Energia final armazenada: {res.E_stored()[-1] * 1e6:.2f} µJ")

⚠️ 19. Erros Comuns e Como Evitá-los

1. "Missing ground node '0'"
Motivo: Nenhum nó do circuito se chama "0".
Solução: Renomeie o polo de referência para "0".
2. "Circuit has floating sub-circuit"
Motivo: Uma ilha de componentes não tem caminho condutivo até o terra.
Solução: Conecte uma referência ao terra nesse sub-circuito.
3. "Loop of ideal voltage sources"
Motivo: Duas fontes de tensão ideais foram ligadas em paralelo ou em laço fechado.
Solução: Insira uma pequena resistência interna em série com a fonte.
4. "Tolerance must be positive"
Motivo: Ao definir tolerância em resistores ou na CLI (--tol), foi passado um valor negativo ou nulo.
Solução: Use valores positivos (ex: 0.05 para 5%).

Hipóteses matemáticas

Transitório: apenas elementos lineares; semicondutores geram erro explícito. UIC aplica condições iniciais; sem UIC o início é o ponto DC. Na varredura, os pontos são start+k·step até o limite, sem modificar o circuito recebido.

Os cantos da sensibilidade são estimativas locais, sem garantia de extremos globais. RSS não implica 3σ: para tolerâncias uniformes independentes, σ(V)≈RSS/√3; correlações exigem covariâncias. O Pareto representa impacto absoluto linear.

O solver AC retorna fasores de pico. O construtor trifásico converte V_rms para amplitude de pico; divida os fasores complexos de tensão e corrente por √2 antes de passá-los aos wattímetros.

Dois wattímetros: fasores RMS e três fios, Ia+Ib+Ic=0. S=Vac·conj(Ia)+Vbc·conj(Ib), P=Re(S), Q=Im(S), inclusive com desequilíbrio e sequência inversa. Com neutro conduzindo, some as três potências fase–neutro.
